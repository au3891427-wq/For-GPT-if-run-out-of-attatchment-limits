# Assassin Dagger Resource Pack Reference

This folder contains the original files extracted from `AssassinDagger-ResourcePack-26.3.zip`.

Purpose: make each resource directly accessible through the public repository for code assistants and reviewers that cannot accept ZIP attachments.

Important:
- This is an unmodified reference copy of the supplied resource pack.
- It is NOT yet integrated into ArenaSystem Client.
- Do not assume the standalone `pack.mcmeta` should be copied into the mod JAR.
- The server item model identifier is `arenasystem:assassin_dagger`.
- The server-side dagger uses a Golden Sword base item and PDC marker `arenasystem:assassin_blade`.
- Verify Minecraft 26.3 item-definition/model behavior before changing or integrating these assets.
